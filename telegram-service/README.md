# Service Telegram Microservice (GramJS / MTProto)

Microserviço ultra-leve baseado em GramJS (TypeScript/Node.js) para automação de contas do Telegram via protocolo MTProto.

- Conexão nativa via MTProto (GramJS)
- Servidor REST Express para disparar mensagens via n8n
- Persistência de StringSession em arquivo/volume
- Consumo mínimo de memória RAM (<30MB)
